# G2 机关合同

目标：从低处安全点 S 到高处门 G；旋转梯改变第一段路径，观察方向改变第二段路径。
本轮单一核心机关为 Rotator。上一版的平移台暂不进入这条路线，避免同时验证两套机关。

| 节点 | 位置（米，Y 向上） | 行为 |
|---|---|---|
| S | [-3.5, 0, 1.4] | 唯一允许旋转的位置 |
| T | [1.8, 2, 0] | 梯顶等待；不能旋转，可切换视角 |
| A | [2.65, 2, 0] | 近端连接边缘，不保存角色于此 |
| B | [4.05, 3.12, 1.4] | 远端连接边缘，不保存角色于此 |
| F | [4.05, 3.12, 0.2] | 跨越后的稳定平台 |
| G | [5.7, 3.12, 0.2] | 终点；允许返回 |

| 路段 | 激活条件 | 过渡 |
|---|---|---|
| S ↔ T | 旋转状态 0；动画已结束 | 地面移动与逐级上/下楼梯 |
| T ↔ F | 状态 0 + C0 + 动画已结束 | T→A→B→F；A→B 位于遮挡屏后 |
| F ↔ G | 动画已结束 | 固定平台普通移动 |

C0 的目标到相机方向为 [1, 0.8, 1]。B−A=[1.4, 1.12, 1.4]，与该方向平行；正交投影下两条端边的对应位置重合。C1/C2 显示真实深度差。
遮挡屏是实体深灰色面板。几何测试对角色所有顶点在 A→B 的 11 个采样位置作射线投射，确认从 C0 看被该面板遮住。它不是角色透明度渐变或无条件瞬移。
运动件的径向包络半径小于 2.73 m；对固定建筑做连续圆柱包络分离检查，并额外以 5° 间隔检查网格 AABB。角色在 S 时也在包络外。机关基座与其内部装配接触不作为环境碰撞。
跨深度部分是预先指定的视错觉路线，不是通用物理寻路；本轮不开放自由行走。

动画开始时只建立 pending 状态，结束时原子提交新节点/梯态/视角。动画中 MOVE、BACK、ROTATE、CAMERA、UNDO 都被拒绝；RESET 可以打断并使旧完成回调失效。
暂停冻结动画进度，失焦自动暂停；刷新从上一个已提交的稳定状态恢复。当前只实现本地稳定快照，撤销历史不跨刷新保存。

数据版本：schema=1；level=atrium-g2-02。损坏存档、不同关卡版本、浮点梯态或角色在梯上而梯态不是 0 的存档均不载入。读取失败使用初态，只有玩家后续稳定操作才写入新状态。

待实机观察：面板是否过大/过小、相机转动的舒适度、角色阴影是否泄露跨深度过渡、点选是否准确，以及玩家能否自行理解连接条件。

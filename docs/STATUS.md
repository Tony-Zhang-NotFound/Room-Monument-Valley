下一次验证应先在实际桌面浏览器中完成以下动作：

1. 初始状态不能上楼，旋转一次后能上楼；站在梯上不能旋转。
2. C1/C2 看见深度分离，只有 C0 能跨越；三个画面比例下没有可见跳帧或接缝。
3. 走到遮挡屏附近时暂停、继续；快速重复输入不会多走一步。
4. 动画途中刷新，回到最近的稳定点；关闭再打开能恢复；禁用存储仍可玩。
5. 抵达后返回、撤销、重新开始都有效；减弱运动模式能完成同一路线。
6. 记录 GPU/浏览器/分辨率、帧时间和视觉缺陷；邀请一名未看解法的试玩者描述机关。

如果出现问题，附起始节点、梯态、视角和操作顺序。不要在本轮候选验收完成前扩展第二间房间或接云端。
